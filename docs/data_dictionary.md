# Data Dictionary

All data is synthetic, generated by `src/generate_data.py` (seed 42). Raw CSVs are in `data/raw/` (not committed; `make generate` recreates them). Up to 1,000 rows per table are committed in `data/sample/`.

## Time conventions

| Column | Clock |
|---|---|
| `fact_appointment.booked_at`, `scheduled_at`, `status_updated_at` | Clinic-local wall time (no offset stored) |
| `fact_experiment_assignment.assigned_at` | UTC |
| `fact_message_log.sent_at` | UTC |
| `dim_clinic.timezone` | IANA zone; C05, C12, C21 are `America/Chicago`, the rest `America/New_York` |

Staging converts UTC to clinic-local with `(ts AT TIME ZONE 'UTC') AT TIME ZONE clinic.timezone`.

## Raw tables

### dim_patient (90,000 rows)
| Column | Type | Notes |
|---|---|---|
| patient_id | text | PK, `PT000001` |
| age_band | text | 0-17, 18-34, 35-49, 50-64, 65-74, 75+ (depends on payer) |
| sex | text | F / M |
| payer_type | text | commercial 50%, medicare 22%, medicaid 23%, self_pay 5% |
| zip3 | text | 460-475 (simulated) |
| preferred_language | text | English, Spanish, Other. Spanish is more common in Medicaid (27% vs. 10%) |
| sms_opt_in | bool | 70% Medicare, 82% others. Only opted-in patients are eligible for the experiment |

### dim_clinic (24 rows)
clinic_id (PK, `C01`..`C24`), clinic_name, specialty (primary_care, cardiology, orthopedics, behavioral_health, dermatology, ob_gyn; 4 clinics each), region, timezone, has_waitlist. C17 is the largest primary-care clinic (1.8x mean volume).

### dim_provider (180 rows)
provider_id (PK), clinic_id (FK), specialty. Allocated to clinics in proportion to volume.

### fact_appointment (≈420,000 rows; 2024-01-01 to 2025-12-31)
| Column | Type | Notes |
|---|---|---|
| appointment_id | text | PK |
| patient_id, clinic_id, provider_id | text | FKs |
| booked_at | timestamp | local. **0.5% are after scheduled_at** (entry error) |
| scheduled_at | timestamp | local, weekdays 08:00-16:40, excluding 12 holidays |
| lead_time_days | int | floor((scheduled - booked) / 1 day). Negative on the error rows |
| status | text | **Inconsistent codes**: completed / Completed / COMPLETED, no_show / NOSHOW / No Show / NS, cancelled / Cancelled / CANCELED, late_cancel / Late Cancel / LATE_CANCEL, rescheduled / Rescheduled |
| status_updated_at | timestamp | local; cancellation time, or visit + 0.5-3 h |
| slot_refilled_flag | text | Y / N for cancelled and late_cancel; NULL otherwise |
| rescheduled_from_appointment_id | text | Set on appointments created by a reschedule; points to the original |

### fact_experiment_assignment (≈31,000 rows)
assignment_row_id (PK), patient_id, variant (control / treatment), assigned_at (UTC), clinic_id_at_assignment. One row per patient, except for planted issues.

### fact_message_log (≈300,000 rows)
message_id (PK), appointment_id (FK), sent_at (UTC), channel (sms_one_way / sms_two_way), delivery_status (delivered / failed / undelivered / **NULL**), reply_code (C confirm, R reschedule link tapped, X cancel; two-way only).

## Planted data-quality issues

| Issue | Size | Where fixed |
|---|---|---|
| Status-code spellings | 15 raw codes for 5 statuses | `sql/01_staging/02_stg_appointment.sql` |
| Rescheduled originals mis-coded as no-show | 60% of the ≈1.2% rescheduled originals | same file: re-labelled when a child row points to the original |
| booked_at after scheduled_at | 0.5% | same file: flagged, lead time NULL |
| Duplicate assignment rows with conflicting variants | 0.7% of assigned patients | `03_stg_assignment.sql`: first row by assigned_at wins |
| SRM: C17 treatment assignments missing 2025-04-07 to 2025-04-15 (local date) | all treatment rows in that cell | detected and excluded in `src/analysis.py`; exclusion stored in `ref_srm_exclusion` |
| sent_at UTC vs. local scheduled_at | all messages | `04_stg_message.sql` |
| NULL delivery_status | 2% | `04_stg_message.sql` maps to 'unknown' |

## Generator assumptions (documented, not real-world benchmarks)

- **Visits per patient:** Poisson, with a Gamma-distributed rate (shape 1.4) scaled by specialty (behavioral health 2.2x, OB 1.4x, dermatology 0.6x). Weekday weights: Mon 1.12, Tue 1.05, Wed/Thu 1.0, Fri 0.83.
- **Lead time:** lognormal, with median by specialty (7 days for behavioral health, 28 for dermatology) and sigma 0.8. 8% are same-day or next-day.
- **Latent no-show propensity:** p_i ~ Beta(mean = payer rate, concentration 1.3). Payer control rates: 9 / 12 / 22 / 24%. Treatment multiplies p_i by (1 - |effect| / control rate), so payer means shift by -1.0 / -1.5 / -4.0 / -3.0 pp.
- **Outcome sequence per appointment:** early cancel 8% (refilled 85%), then late cancel 6.0% control / 7.5% treatment (refilled 25% / 60%), then no-show with probability p_i / (1 - late-cancel rate), so the no-show rate within the slot universe equals p_i.
- **Reschedules:** 1.2% of appointments booked at least 30 h ahead. The new appointment lands 3-28 days later.
- **Message delivery:** 96.5% delivered, 2.5% failed, 1% undelivered, then 2% of rows overwritten to NULL.
